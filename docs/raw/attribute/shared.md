
WidgetAuthorization
===================



view_permissions
----------------

- Type: `set` of `string`

The names of the permissions users are required to have to view this attribute in the user management
widget. An empty set means no restriction.



edit_permissions
----------------

- Type: `set` of `string`

The names of the permissions users are required to have to edit this attribute in the user management
widget. An empty set means no restriction.
