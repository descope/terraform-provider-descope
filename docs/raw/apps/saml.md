
SAMLApp
=======



id
----

- Type: `string`

An optional identifier for the application. When omitted, an identifier is generated by the
server. Can only be set when the application is created, and changing it will require the
resource to be deleted and recreated.



project_id
----------

- Type: `string` (required)

The ID of the project that this application belongs to. Changing this value will require the
resource to be deleted and recreated.



deletion_protection
-------------------

- Type: `bool`

Protects the application from being accidentally destroyed or replaced. Destroying or replacing
a federated application breaks the service provider's configured integration, so these
applications are protected by default. To allow the resource to be destroyed or replaced, for
example in ephemeral test environments, set this attribute to `false` and apply the change first.



name
----

- Type: `string` (required)

A name for the SAML application.



description
-----------

- Type: `string`

A description for the SAML application.



logo
----

- Type: `string`

A logo for the SAML application. Should be a hosted image URL.



disabled
--------

- Type: `bool`

Whether the application should be enabled or disabled.



login_page_url
--------------

- Type: `string`

The Flow Hosting URL. When left empty the project's default login page URL is used, and the
computed value is reflected in this attribute. Read more about using this parameter with custom
domain [here](https://docs.descope.com/sso-integrations/applications/saml-apps).



dynamic_configuration
---------------------

- Type: `object` of `apps.DynamicConfiguration`

Connection details are retrieved dynamically from the SP's metadata URL. Exactly one of
`dynamic_configuration` and `manual_configuration` must be set.



manual_configuration
--------------------

- Type: `object` of `apps.ManualConfiguration`

Connection details are provided manually. Exactly one of `dynamic_configuration` and
`manual_configuration` must be set.



acs_allowed_callback_urls
-------------------------

- Type: `set` of `string`

A list of allowed ACS callback URLS. This configuration is used when the default ACS URL value is unreachable. Supports wildcards.



subject_name_id_type
--------------------

- Type: `string`

The subject name id type. Choose one of "", "email", "phone". Read more about this configuration [here](https://docs.descope.com/sso-integrations/applications/saml-apps).



subject_name_id_format
----------------------

- Type: `string`

The subject name id format. Choose one of "", "urn:oasis:names:tc:SAML:1.1:nameid-format:unspecified", "urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress", "urn:oasis:names:tc:SAML:2.0:nameid-format:persistent", "urn:oasis:names:tc:SAML:2.0:nameid-format:transient". Read more about this configuration [here](https://docs.descope.com/sso-integrations/applications/saml-apps).



default_relay_state
-------------------

- Type: `string`

The default relay state. When using IdP-initiated authentication, this value may be used as a URL to a resource in the Service Provider.



default_signature_algorithm
---------------------------

- Type: `string`

The signature algorithm used to sign SAML responses. Choose one of `""` (default, SHA-1) or `"sha256"` (SHA-256). Only applies to IdP-initiated flows — SP-initiated flows use the algorithm specified in the SP's SAML request.



attribute_mapping
-----------------

- Type: `list` of `apps.AttributeMapping`

A list of attribute mappings from Descope user attributes to SAML assertion attributes.



force_authentication
--------------------

- Type: `bool`

This configuration overrides the default behavior of the SSO application and forces the user to authenticate via the Descope flow, regardless of the SP's request.



logout_redirect_url
-------------------

- Type: `string`

The URL to redirect to after logout. When the service provider sends the user to the
`idp_logout_url`, Descope logs the user out and then redirects them to this URL.



error_redirect_url
------------------

- Type: `string`

The URL to redirect to when an error occurs.



idp_logout_url
--------------

- Type: `string`

The logout URL of the application, to set as the sign-out URL in the service provider. This
value is set by the server and is read-only.



single_logout_enabled
---------------------

- Type: `bool`

Whether SAML Single Logout (SLO) is enabled for the application. When enabled, the service
provider can log the user out by sending a signed `LogoutRequest` to the `idp_logout_url`, and
Descope sends a `LogoutRequest` to the service provider when a logout reaches the user's applications
(logout of all devices, an admin logout, or another application's logout that propagates). The request
names the user by the application's NameID, and it is sent to every application with single logout
enabled that the user can sign in to, including ones the user hasn't used.



sp_single_logout_url
--------------------

- Type: `string`

The service provider's Single Logout Service URL that logout requests are sent to. Required when
`single_logout_enabled` is `true` and `manual_configuration` is used. With `dynamic_configuration`
it can be left empty to take the URL from the service provider's metadata.



sp_single_logout_binding
------------------------

- Type: `string`

The SAML binding used for `sp_single_logout_url`. Choose one of `""`, `"redirect"`, `"post"` or
`"soap"`. When `sp_single_logout_url` is set, an empty value means `"redirect"`, and when it's
empty the binding is taken from the service provider's metadata. The `"soap"` binding sends the
logout request directly from Descope to the service provider and requires an `https` URL.



single_logout_propagation
-------------------------

- Type: `string`

What a logout started by the service provider reaches. Choose one of `""` (default, same as
`"allApps"`), `"allApps"` to also log the user out of their other applications, or
`"none"` to only end the user's session without notifying any other application.



single_logout_scope
-------------------

- Type: `string`

Which Descope sessions a logout started by the service provider ends. Choose one of `""`
(default, same as `"session"`), `"session"` to end only the session the logout request refers to,
or `"allSessions"` to end every session of the user.





DynamicConfiguration
====================



metadata_url
------------

- Type: `string` (required)

The metadata URL when retrieving the connection details dynamically.





ManualConfiguration
===================



acs_url
-------

- Type: `string` (required)

Enter the `ACS URL` from the SP.



entity_id
---------

- Type: `string` (required)

Enter the `Entity Id` from the SP.



certificate
-----------

- Type: `string`

Enter the `Certificate` from the SP.
